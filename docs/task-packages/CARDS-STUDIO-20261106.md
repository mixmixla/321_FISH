# 璀璨宝石与情书 · 卡牌插画 v1

从 GitHub main 36ff593 开发，按用户要求为卡牌本身做原创美术。由主控集成、独立评审、后台全量，正常 PR 合并 main。开发与试运行不接管用户桌面。

- 璀璨宝石。每级 20 张发展卡各有独立画面，三级分别表现矿场、工坊和商贸城市。五位贵宾用肖像区别。每张卡发牌时拥有稳定图号；同一张进入市场、私人保留区及自己的已购收藏后仍是同一图。费用、折扣、积分、取宝石/留牌/买牌等沿现行规则，旧卡可显示费用和回退牌面。
- 情书。八个角色使用原创肖像和清晰的中文身份、点数；本人回合可看到持牌与可出的新摸牌，正常选择要弃的牌、目标和猜值；旁观者与其他玩家只可看公开弃牌。
- 插画组拥有图库位图和资产说明。桌面组负责 client_gameui.py / client.py；网页组负责 web.py / 专属网页模块；主控负责私有数据和图号、公共图库、合并及验证。各组在独立工作树工作，复用 /game-art/ 与现有打包数据目录。
- 验收以桌面对局、390px 手机和实际卡片流转为准；卡画不能盖住数值和按钮，手牌与收藏不出现在其他人的私有状态中。先跑相关测试，最终同一候选完整覆盖一次。界面检查使用合成资料、隔离桌面/无头浏览器。
