- 原Pro《项目接管审查》R0–R4/CC-01–CC-05与2026-10-01最新CC-02架构审查建议，按实际PR #4交付映射。

- AI_COMMAND_CENTER是唯一状态写入源；docs/任务清单是从其指定区块生成的阅读视图，不独立手填状态。

- AGENTS/README可找到清单、权威状态与接续指南；有限Goal启动、同聊天恢复、跨聊天接管和防重复规则落盘。
- 来源文档只写脱敏摘要和事实映射，不复制私有聊天全文、会话标识或本机凭据。

主控拥有AGENTS、README、指挥中心、任务清单/归档、接续指南、本Task/Review；
文档worker仅写路线来源与任务映射；独立代理只读审查，不能自行验收自己的写入。

## 验收

1. 用户打开清单即可定位当前R1状态、PR #4、下一CC-02设计审查和后续R2/R3/R4。
2. 新聊天从AGENTS恢复范围、版本、主控、Goal状态、进程/日志与下一动作；旧Goal仍活跃时不重复启动。
3. 阅读视图与CC源区块完全一致；新建议和Pro原建议/用户批准有区别；旧ID别名不会使已完成任务重做。
4. 相对链接、diff-check和文档边界通过，源码300项原字节保持，独立资料审查可接受。
5. 打开最终清单，Goal实际目标完成后标记complete；不启动新的产品Goal或修改已暂停R1 heartbeat。

不改应用/测试/依赖，不跑全量；不commit/push、创建新PR/聊天、发Pro消息、merge/release或启用设备。
