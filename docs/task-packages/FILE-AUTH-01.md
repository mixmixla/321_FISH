在现有锁内查找并校验角色后才删除记录；其它 handlers 的既有检查只加回归，不改逻辑。

| 操作 | 沿用的合法角色 |
| --- | --- |
| ACCEPT / REJECT / CHUNK_ACK / VERIFY | 记录中的接收者 UID |
| LISTEN / DIRECT_OK / DATA | 记录中的发送者 UID |
| CANCEL | 任一记录参与者 UID |

非法角色和未知 ID 沿用安静忽略，不新增错误帧或协议行为。接收者 ACCEPT 后发送者离线的
可用性/状态阶段竞态仅记录，不能纳入此次身份鉴权修复。

不改群文件库、Web 附件/API、账号/管理员认证、客户端 UI、游戏、媒体设备、公开 Git 历史、
运行入口或固定门禁基础设施。不增 skip、不重试取绿、不删弱既有断言。
