## 状态、布局与操作设计

| 状态 | 呈现 | 允许操作 |
| --- | --- | --- |
| 等人 | 房间、玩家/观战身份、人数与规则摘要 | 房主满足人数可开始；离开/收起可用 |
| 本人回合 | 明确“轮到你”、本人的黑/白或红/黄棋、坐标/列提示 | 空交点或未满列可落；键盘/按钮入口仍可用 |
| 对方回合 | 对手名字、等待提示、自己棋色 | 不发送落子，保留规则/收起/离开 |
| 观战 | 显式“观战”，双方棋色与回合 | 棋盘只读，不能提交玩家动作 |
| 结束 | 胜者或平局、最后落子、胜线；保留棋盘 | 禁用落子，显示既有自动复位/房主再开语义 |
| 暂断/被撤权/离房 | 沿现有 Core 状态与失效流程清理 | 不把旧局动作发给新房间，不自动重开 |

- 五子棋用交点几何统一画子/点击/悬停，边缘采用半格有效范围和最近交点；拒棋盘外与占用点。
  四子棋显示可落列与底部预计位置，满列不可落，点击范围限定棋盘/列提示区。
- 回合与棋色从 players 顺序和 turn_uid 得出，不能将“自己回合”等同“执黑”。
  胜线从最终 board/last_move 计算显示，不改变服务端胜负规则/协议；服务端仍是最终动作权威。
- 正常和最小窗口下棋盘、状态、离开/收起/规则不裁切；文本优先可读，视觉采用现有办公主题色。
  不新增位图资产或依赖。保留最后落子指示；这两款取消持续 idle 呼吸/循环胜利粒子，
  只保留短暂落子反馈，收起时停止动画调度而继续接收核心状态。
- 收起主窗时同步藏起大厅与专注窗；恢复仅还原此前可见且尚存的窗口，不自动创建新窗/重开游戏。
  隐藏期间的房间更新不弹出抢焦点；老板键既有静音/状态恢复保持，切换路径不得丢失窗口状态。
- Web 两款同步本人/观战/终局操作门禁与胜线/最后落子；在窄宽度下坐标按 canvas 实际 CSS 比例换算。
  不把单元/Node DOM 桩等同真实浏览器，验收分别记录。
