## 状态、布局与操作设计

| 状态 | 呈现 | 允许操作 |
| --- | --- | --- |
| 等人 | 房间、玩家/观战身份、人数与规则摘要 | 房主满足人数可开始；离开/收起可用 |
| 本人回合 | 明确“轮到你”、本人的黑/白或红/黄棋、坐标/列提示 | 空交点或未满列可落；键盘/按钮入口仍可用 |
| 对方回合 | 对手名字、等待提示、自己棋色 | 不发送落子，保留规则/收起/离开 |
| 观战 | 显式“观战”，双方棋色与回合 | 棋盘只读，不能提交玩家动作 |
| 结束 | 胜者或平局、最后落子、胜线；保留棋盘 | 禁用落子，显示既有自动复位/房主再开语义 |
| 暂断/被撤权/离房 | 沿现有 Core 状态与失效流程清理 | 不把旧局动作发给新房间，不自动重开 |

- 五子棋用交点几何统一画子/点击/悬停，边缘采用半格有效范围和最近交点；拒棋盘外与占用点。
  四子棋显示可落列与底部预计位置，满列不可落，点击范围限定棋盘/列提示区。
- 回合与棋色从 players 顺序和 turn_uid 得出，不能将“自己回合”等同“执黑”。
  胜线从最终 board/last_move 计算显示，不改变服务端胜负规则/协议；服务端仍是最终动作权威。
- 正常和最小窗口下棋盘、状态、离开/收起/规则不裁切；文本优先可读，视觉采用现有办公主题色。
  不新增位图资产或依赖。保留最后落子指示；这两款取消持续 idle 呼吸/循环胜利粒子，
  只保留短暂落子反馈，收起时停止动画调度而继续接收核心状态。
- 收起主窗时同步藏起大厅与专注窗；恢复仅还原此前可见且尚存的窗口，不自动创建新窗/重开游戏。
  隐藏期间的房间更新不弹出抢焦点；老板键既有静音/状态恢复保持，切换路径不得丢失窗口状态。
- 本项旗舰验收只针对Windows桌面。Web保留已有功能，按CC-03证据独立分类；Web完整等价
  交点/棋色/动作门禁/胜线与SSE旧状态契约未冻结，不冒称同等旗舰或跨端体验已验收。
  范围收窄决定来源：用户允许缩小实现、Windows优先；独立复审已认可桌面契约，Web缺口不混入桌面结论。

## 独立设计审查补正契约（v1.1）

resource_review 未参与实现，从实际调用链要求将下列细节固定为验收条件；v1 尚未获准编码，
本修订不改变游戏规则或扩大到其它游戏。

1. 五子棋独立交点命中：以绘制的 ox/oy/cell 为同一基准，最近交点取 floor(v+0.5)，
   半格边界左/上包含、右/下不含；边界外及占用点不提交。hover与点击共用命中函数。
   四子棋 y 范围限定棋盘及其正上方一格列提示区，x 范围按7列；满列无预览/提交，
   预览显示该列实际最底空位。其它棋类的 _cell_of/_click_move 语义保持。
2. 两棋的点击、参数按钮、最后 _do_action 共同使用最新 Core 状态作门禁：connected、
   playing、me在room.players且不在spectators、turn_uid==me、无winner/draw。
   UI上下文携带本次渲染room_id/round，异步旧回调与最新房间/轮次不符时不发；不能仅依赖旧ui.can_move。
   终局/离房/被撤权只读。玩家0始终黑/红、玩家1白/黄，无论当前轮到谁均显示自己的颜色；
   观战者不显示“你执子”。所有门禁仅客户端提示，服务端权威判定不变。
3. 胜线从最终board/last_move与winner对应棋色计算：枚举横、竖、右下、右上，
   取首条满足>=5/>=4的最大连续同色段（包括长连全部棋子），绘制两端中心之间的线。
   不通过last_move的旧连线不选；last_move无效、平局或没有winner不画，不能捏造胜利。
   终局期间保留线，复位/new round立即清线和旧落子动画。
4. 两款painter取消idle呼吸和循环胜利星点，只在last_move变化后的<=0.9秒保留短反馈。
   GameWindow/BoardFocusWindow分别持有自己的after标识；隐藏/销毁/换房/换轮取消已排队动画，
   _render_to/repaint回调还须检查目标窗口存在且可见。收起期间Core继续更新，恢复画最新态。
5. 收起事务保存对象身份及主窗/大厅/专注窗各自可见性，不以“对象存在”代替“之前可见”。
   mini与boss重复/嵌套进入不得覆盖原快照；恢复只还原同对象、仍存在、未被手动关闭/隐藏的窗口。
   GameWindow.hide用于收起和手动隐藏时需能区分原因，手动隐藏/close使相应待恢复标志失效。
   所有窗口都不因收到游戏帧自动弹出；恢复不新建窗口、不join/start、不撤销老板键静音/状态规则。
   show_main的用户显式恢复行为保留，隐藏子窗的还原须满足前述快照，而非一律show。

必须实际验证：五子棋四边半格/占点、四子棋上下空白/满列、白方本人回合与观战、旧轮回调、
横竖两斜及长连/平局胜线、两个窗口同时存在的独立动画、mini→boss嵌套、手动关闭后恢复、
收起期间新快照/终局到达后恢复。现有泛用动画纯函数测试不删，其它游戏可继续使用原动效。
