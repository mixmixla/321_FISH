# 山屋惊魂 · 2026-11-06 v1

从 main c4b2754 开发。开门探索应当揭示一幅能与既有房间拼接的真实俯视插画；同一局的发现者、房间和已揭物品、事件、预兆可回看。适用于 Tk 与网页，使用合成资料、私有桌面及无头浏览器，主控验收后通过 PR 合并 main。

- 房间。按 ROOM_SHORT 实际顺序绘制含门厅和出口在内的 21 格方形图块，统一正俯视、比例和四边中央门槛。地图只画已揭示的坐标，显示玩家、当前位置、惊魂出口；可点门移动或开新房。远出口和扩大地图时仍能读图、移动。
- 卡画。完整覆盖 6 件物品、8 个事件、8 个预兆。首次开门后显示本次真实抽牌与结果，可回看房间发现，意外的馈赠保留额外物品。走回老房不重复抽牌；保留原有属性、道具、惊魂和撤离玩法。
- 分工。两插画组各写自己的图库；桌面组独占 client.py / client_gameui.py 及专属绘制模块，网页组独占 web.py 及专属绘制模块；主控维护规则发现记录、共享图号与图库路径。旧 rooms 的简称合同保留，不广播未探索的房间、牌序或暗牌。
- 验收。合成三人对局用正常动作开门、走回和查看卡；核对两端小屏、真实截图、同回合坐标/属性和揭牌一致。优先受影响验证，最终完整覆盖并核对远端。
