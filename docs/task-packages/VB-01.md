# VB-01 v1 — 可恢复的隔离逐文件门禁

授权：[本地自治决定](../decisions/LOCAL-AUTONOMY-20261003.md)。主控内部批准；基线 452417e。
状态以[指挥中心](../AI_COMMAND_CENTER.md)为准。

目标：将历次 ignored 辅助脚本的逐文件验证变成可从仓库复现的正式入口，避免全套单进程 Tk
污染，保留真实失败并绑定候选。先补门禁再验证后续可靠性/游戏/构建，减少重复临时工具。

范围：run.py、dev.ps1、新 test_gate.py/test_sandbox.py（如必要）、tests/conftest.py 的测试隔离入口、
tests/test_test_gate.py 及必要 runner 测试、开发说明/技能参考。主控写治理/Task/Review/状态，
唯一 worker 写 runner 和其测试；应用业务源码不改。邻接边界调整须在本 Task 说明。

必须行为：
- 默认及 test-all 按 tests/test_*.py 排序逐文件独立进程；test 保留专项入口；每文件独立 basetemp。
- UTF-8 日志、机器可读进度/summary、命令/解释器/环境说明/输入文件 hash/内容标识、真实退出/耗时。
  crash/timeout/collection/无测试不能当成功，不自动重试或隐藏失败，默认 opt-in skip 不变。
- 新运行唯一目录；续跑只允许相同源码/测试/依赖/命令/解释器/环境配置、已记录日志完整，
  已结束失败不重跑覆盖；中断未结束项保持 interrupted 证据后重新执行。清理仅自己创建的进程树。
- 执行使用隔离源副本（仅版本控制的项目源/必要静态资产，不拷贝真实运行数据）、合成 profile，
  因 config/prefs 默认写源码旁，不能只改 USERPROFILE；清除敏感部署/模型/Agent环境且不打印值。
- 测试网络仅 loopback，禁止真实外部 Agent 工具/设备；必要测试专用 guard 必须明确记录，
  不用于改变业务断言/跳过测试。GUI 测试在隔离 Windows desktop 中执行，不抢用户焦点。
- 不改变系统全局配置、不读真实 prefs/history/audit/私钥；不自动安装依赖/禁用安全门禁。

验证：小型真实子进程 PASS/FAIL/collection/empty/crash/timeout/断点续跑、版本不匹配拒绝、
隔离 profile/写入路径/loopback/Agent阻断及独立审查；受影响 runner 专项；候选冻结后完整逐文件门禁。
不同步修改应用行为和跑最终门禁；全部失败保存。开发机 GUI/非开发机器/物理网络分别记录。

完成：入口可重跑、必测通过、独立审查无必须项、候选/证据可恢复后 AI_ACCEPTED。
回退：本地 revert 本任务明确提交；隔离产物留 _tmp_gui 供诊断，不删除或覆盖用户数据。
