# Ollama IDE 工作台 — 优化清单

> 归档时间：2026-09-07
>
> 背景：对本项目（FastAPI + Ollama 本地 Agent + Web 前端，可打包 exe）与市面竞品（Trae / WorkBuddy / Codex / Claude Code）对比后，整理出可在本项目落地的优化项。

## 一、与竞品差距总览

| 维度       | 本项目                 | Trae（字节）     | WorkBuddy（腾讯） | Codex（OpenAI）   | Claude Code（Anthropic）        |
| ---------- | ---------------------- | ---------------- | ----------------- | ----------------- | ------------------------------- |
| 形态       | 本地 Web 应用 + exe    | AI 原生 IDE      | 桌面 Agent        | 云沙箱 Agent/CLI  | 终端 Agent                      |
| 模型       | 本地 Ollama（7b/1.5b） | 云端多模型       | 混元 + DeepSeek   | GPT 代码系列      | Claude 高端模型                 |
| Agent 模式 | 对话/Agent/规划        | IDE/SOLO/Builder | Ask/Plan/Craft    | 云端多 Agent 并行 | Plan/子 Agent/Hook              |
| 上下文管理 | 按轮硬裁剪             | 10 万+ 文件检索  | 三层语义索引      | WorkTree 分支隔离 | 超大上下文 + CLAUDE.md + Memory |
| 工具生态   | 7 工具 + 验证层 + MCP  | MCP + 插件       | MCP + SKILL.md    | MCP               | MCP + 子 Agent + Hook           |
| 可执行域   | 本地项目根             | 本地             | 授权 + 沙盒       | 云端沙箱          | 四级权限 + 本地                 |
| 记忆/规则  | **无**           | .trae/rules      | MEMORY.md         | AGENTS.md         | CLAUDE.md 项目记忆              |

## 二、不足清单（按优先级）

### P0 — 现在就值得做（改动集中、见效快）

| # | 项目                         | 对应不足          | 涉及文件                                                                                                    |

### P1 — 明显提升体验（中量改动）

## 三、执行策略

- **一次做一项**，每项做完重启验证，避免改动过多增加调试成本。
- 推荐落地顺序：
  1. AGENTS.md 规则注入（#1）
  2. 高危命令拦截（#2，安全兜底）
  3. 变更摘要 / 待确认合并面板（#4，视觉冲击最强）
  4. 其余按需选做
