# Windows 开发环境

本项目使用 Python **3.14.5**，版本由根目录 `.python-version` 固定。
使用 PowerShell 7（`pwsh`）执行以下命令。已有系统 Python 可以保留。

## 首次配置

先按 [pyenv-win 官方安装说明](https://github.com/pyenv-win/pyenv-win#installation)
安装 pyenv-win，重新打开终端后，在项目目录执行：

```powershell
pyenv install -q 3.14.5
pyenv local 3.14.5
pyenv exec python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -c "import sys, tkinter; print(sys.version); print(sys.executable)"
```

`cryptography` 是加密通信的必需依赖；`pytest` 是测试依赖；`Pillow` 用于
图片显示、截图与屏幕共享；`PyInstaller` 用于打包；`pystray` 支持客户端和服务器系统托盘。
语音转写、翻译和 Lottie 是另行启用的可选功能，需相应依赖及模型；未安装时按既有逻辑降级。

## 日常运行

推荐用 `dev.ps1`，它始终调用项目 `.venv`，不受 PATH 中旧 Python 的影响：

```powershell
.\dev.ps1                 # 默认：按 tests/test_*.py 排序逐文件隔离门禁
.\dev.ps1 test-all        # 同上，可配 --label/--resume
.\dev.ps1 test -k three_modes_render_different  # 单进程专项调试
.\dev.ps1 server          # 服务器
.\dev.ps1 client          # 客户端
.\dev.ps1 client --host 192.168.1.10
.\dev.ps1 build           # EXE 打包
```

也可以直接执行 `.\.venv\Scripts\python.exe run.py`。启动聊天时先启动
服务器，再启动客户端。分支、提交和 PR 约定见根目录 `COLLABORATION.md`。

普通门禁不访问摄像头，也不执行屏幕截图比较。需要这些检查时单独运行专项入口：

```powershell
.\dev.ps1 test --run-visual -k three_modes_render_different
# 确实需要摄像头真机采集验证时：
.\dev.ps1 test --run-hardware -k real_camera_capture
```

`.venv` 不提交到 Git；`.python-version` 与 `requirements-dev.txt` 提交，
方便协作者复现环境。

默认门禁入口 `run.py`/`dev.ps1 test-all` 使用 `test_gate.py`：每个测试文件都在
独立子进程、独立 `--basetemp` 和合成 profile 中执行，UTF-8 原始日志、进度和
`summary.json` 保存在 `_tmp_gui/test-gate/<run-id>/`。源码快照只包含代码、测试、
配置和静态资产，排除 `prefs.json`、history、audit、server_state、web_files、
模型与私钥；子进程网络仅允许 loopback，广播和 wildcard bind 的本地 remap 会写入
sandbox 证据，真实 Agent、摄像头和麦克风调用会失败。包含 Tk 的测试在 Windows
private desktop 上执行，不能抢当前桌面。

中断后使用原 run 目录恢复：

```powershell
python run.py test-all --resume _tmp_gui\test-gate\<run-id>
```

恢复会核对源码/测试/依赖、Python 解释器、命令与环境指纹；已结束的失败、收集错误、
空测试和超时不会被覆盖，只有上次未结束的项会留下 `interrupted` 记录后重跑。pytest
参数仍可通过 `dev.ps1 test -k <关键词>` 或 `python run.py test -k <关键词>` 透传到
单进程专项入口。

注意：显式 `test` 是历史调试入口，不使用源码副本、网络/设备guard或private desktop。
执行它前须自行核实测试数据和外部副作用；需要本轮安全隔离验证时，使用
`dev.ps1 test-all tests/test_<name>.py --label <label>`，不能把单进程调试结果冒充隔离门禁。
