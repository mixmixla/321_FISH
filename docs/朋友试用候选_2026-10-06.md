## 开发者本地构建

沿用本仓库 `.venv`、Python版本与现有PyInstaller，不改变依赖。先运行：

```powershell
.\.venv\Scripts\python.exe local_trial.py build --source-dir . --output-root _tmp_gui/friends-build
```

读取新build目录 `summary.json` 的 `source_copy`，在该独立源码副本构建入口。下面开发示例使用现有OS-only环境函数，不复制部署token或密码（将 `<source_copy>` 换成刚生成的路径）：

```python
from pathlib import Path
import subprocess, sys
import local_trial
source = Path('<source_copy>')
command = [sys.executable, '-m', 'PyInstaller', '--onefile', '--console',
           '--clean', '--noconfirm', '--name', 'StartTrial',
           '--distpath', str(source / 'dist'),
           '--workpath', str(source / '_tmp_gui/entry-work'),
           '--specpath', str(source / '_tmp_gui/entry-spec'),
           str(source / 'friend_trial_start.py')]
subprocess.run(command, cwd=source,
               env=local_trial._build_env(source / '_tmp_gui/entry-build-profile'),
               stdin=subprocess.DEVNULL, check=True,
               creationflags=subprocess.CREATE_NO_WINDOW)
```

用项目Python执行开发样例。最后只复制 `dist/StartTrial.exe` 到包根，`dist/client.exe`/`dist/server.exe`到包的dist；附LICENSE、本说明及验收记录。不要复制源码开发资料、`.venv`、runtime目录、日志或凭据。不得把构建成功等同其它Windows可用。当前包hash和可复现源绑定见[Review](review-packages/FRIENDS-TRIAL-PR-01-r1.md)。
