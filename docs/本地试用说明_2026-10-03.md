# Windows 本地试用候选 — 2026-10-03

本包用于同一台Windows电脑上的合成账号试用。它是本轮AI技术验收候选，未发布、未推送，
不代表整个R1/RETIRE完成。最终验证结果和产物位置见本文末尾与[验证记录](review-packages/REL-01-r1.md)。

## 开始

使用PowerShell 7（`pwsh`），在解压后的包目录执行：

```powershell
pwsh -NoProfile -File .\trial_start.ps1
```

包目录结构为`trial_start.ps1`、`dist/server.exe`、`dist/client.exe`、`README.md`、
`游戏完成度地图.md`、`LICENSE`和`SHA256SUMS.txt`。EXE自带Python运行组件，无需本机安装Python。
本次只在开发机实际验证；其它Windows机器是否缺系统组件仍待试用确认。

脚本启动隐藏服务器与两个客户端窗口，昵称为`REL_trial_alpha`、`REL_trial_beta`。
每次使用随机本机端口和全新独立目录，资料保存在包内`_tmp_gui/trial-start/<本次编号>/`；
本次内容不会自动恢复到下次试用，也不会加载已有用户prefs、聊天或下载。
本包通过该脚本启用loopback，关闭自动发现、托盘、全局热键、摄像头/麦克风和音频设备。
这些设置仅作用于本次子进程；普通EXE默认仍沿原应用配置。

可先执行`pwsh -NoProfile -File .\trial_start.ps1 -DryRun`查看启动计划；它不会启动EXE。
保持脚本所在终端打开，结束时关闭两个客户端，或在终端按Ctrl+C清理本次进程。
客户端左上红色`✕`或迷你条右键菜单的“退出”会真正退出；系统关闭/Alt+F4只收起到迷你条，
游戏窗关闭只隐藏该窗口。两个客户端退出后，脚本会清理本次隐藏服务器。

## 建议试用范围

优先体验两个窗口之间的文字聊天、游戏大厅里的五子棋/四子棋、棋盘与专注窗、窗口内收起恢复。
主窗顶部点`▣`打开“桌游 · 协作大厅”；A在游戏卡片点“＋ 创建”，B在房间列表双击该房间或选中后点“加入”，
房主点左下“开始”。终局后等待约3秒复位，再点“开始”可重开；左下“离开”退出房间。
右侧“棋盘/专注窗”可调整看棋方式。主窗顶部`—`进入迷你条，右键迷你条“显示主窗”恢复。
五子棋点击交点，四子棋点击列；非本人回合、观战和终局期间只读，终局显示胜线，复位后可再开。
14项已确认桌面缺少必要操作的游戏会明确提示当前端不支持。其余游戏按完成度地图标识，
没有因菜单里存在就被认定为完整可玩。

- 未测试物理LAN、非开发Windows机器、真实防火墙/HTTPS、多机文件传输、真实麦克风/摄像头、
