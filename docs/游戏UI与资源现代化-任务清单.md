## 使用这份清单的顺序

1. 先看当前主控Task及已发生的必测FAIL，保持失败、版本与原始证据。
2. 从完成度地图中的确定缺口冻结一个有限整改或验收Task，不批量放行A–F。
3. 当前应用候选全量、独立审查、同版构建和本机验收各自记录；文档校正只做文档/边界检查。
4. 完整GUI/EXE对局和自然退出、独立视觉/可用DPI矩阵、外机Windows、真实LAN仍按可用资源单列；不以源码覆盖或历史包代替。

所有验收建议都需绑定候选与操作：建房/加入/观战/开始、主要动作与非法/非本人回合、结算/复位/再开/退出重入、私有状态、键盘/焦点、普通/最小窗口；相关过程完成后才提升对应分类。进一步视觉目标仍见[雾岸设计](design/UX-01-design-system.md)与[视觉Task](task-packages/UX-VISUAL-CHAT-01.md)，不是当前整项目已完成声明。
