# 管理员凭据与公开仓库安全

仓库已公开。源码没有可用的默认管理员密码；管理员凭据由服务器部署者设置，
不写进 `config.py`、文档、提交、截图、日志或聊天中的 Review Package。

## 配置与启动

- `MOYU_ADMIN_PASSWORD`：管理员密码。未设置、空字符串或纯空白时，管理员登录关闭。
- `MOYU_ADMIN_NICK`：可选登录标识，默认 `L57`，去除首尾空白后须为 1–20 字符。
  空值或过长会使服务器拒绝启动，错误信息不含配置值。
- 管理员昵称始终保留，不走普通账号的首次登录密码绑定；自定义管理员昵称后，
  旧标识 `L57` 也继续保留并拒绝登录，避免被普通账号占用。

用 PowerShell 7 在服务器所在终端输入密码，然后启动服务器：

```powershell
$env:MOYU_ADMIN_NICK = 'L57'  # 可省略；昵称不是密码
$env:MOYU_ADMIN_PASSWORD = Read-Host '输入新管理员密码' -MaskInput
try {
    .\dev.ps1 server
} finally {
    Remove-Item Env:MOYU_ADMIN_PASSWORD -ErrorAction SilentlyContinue
}
```

使用新生成的强随机密码，存入部署者的密码管理器。输入式示例避免在终端历史中写下密码；
服务部署应通过服务管理器的受限环境配置/secret 注入提供同名变量。
程序不会自动读取 `.env` 文件。打包的 `server.exe` 同样继承启动进程的环境变量。
环境配置在创建配置对象时读取，Hub 启动时生成内存 PBKDF2 校验值；修改后须重启服务器。
管理员密码不进入账号快照，配置对象的常规 `repr` 隐藏该字段。

## 桌面与 Web 登录

桌面使用管理员昵称和部署密码。Web 未启用 `MOYU_WEB_PASSWORD` 时，登录框中的
`password` 是昵称/管理员密码；启用站点口令时，`password` 是站点口令，
`nick_pwd` 是昵称/管理员密码。站点口令不能替代管理员密码。
普通账号接口不能修改或清除管理员密码；管理员权限由服务器校验后授予，
客户端传入 `is_admin`、uid 或昵称不能授予权限。

## 旧部署升级

旧源码中的公开固定密码已失去可信性。升级前为服务器设置新密码，重启后用该密码登录；
客户端如保存了旧密码，也须更新为新密码。
不配置时管理员登录关闭，旧账号快照中的密码不会作为回退来源，普通账号和聊天行为照常。
昵称保持默认值可继续复用旧 uid；修改管理员昵称会按既有昵称账号规则分配/复用 uid，
不会迁移旧管理员的历史或群关系，应确认新昵称未被既有普通用户使用。
更换管理员昵称不是撤销曾经泄露凭据影响的办法。

服务器重启后原内存会话和 token 失效，客户端须重新登录。凭据轮换须重启服务，
不会热更新已有会话。服务器注销某个 Web Session 时立即撤销其 token，
其他已认证端按既有多端规则继续在线。关闭网页或断开 SSE 只移除事件连接，
不会立即注销 Session；当前没有显式 Web logout 接口，会话沿用现有闲置超时清理。

## 公开仓库边界

`prefs.json`、聊天历史、审计、`server_state/`、`web_tls/`、下载文件和部署 secret
属于本地数据，不提交、不共享。`.gitignore` 不能保护强制添加、历史提交或额外复制出来的文件。
当前修改移除了可用默认密码，没有重写 Git 历史；旧密码仍可能出现在历史中，所有旧部署须轮换。
管理员密码只在部署侧与服务进程内存在，环境变量仍需由操作系统权限保护；
不要打印环境变量、序列化完整配置或将真实密码传入诊断材料。

本次沿用现有密码校验和网络协议，不新增依赖或完整账号/secret 管理系统。
